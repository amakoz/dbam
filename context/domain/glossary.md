# Glossary: Dbam

Use these words in code, tests, commits and conversations. When a name in the code differs from the term, the term wins in new code; renaming old code is a separate decision.

The UI is Polish first. **PL** and **EN** are the words users see (`src/i18n/pl.ts`, `en.ts`); **name in code** is the identifier. Never translate a Polish UI word into a new English identifier — use the name in code listed here.

## Screening catalog

| term                                                                | means                                                                                                              | name in code                                           | don't call it                                                          |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------ | ---------------------------------------------------------------------- |
| screening — PL **badanie** (profilaktyczne, przesiewowe)            | One preventive check in the curated catalog, the same for every user.                                              | `screening_catalog` row, `CatalogEntry`                | "exam" or "test" for the catalog item; the user's own exam (see below) |
| przesiew / badania przesiewowe                                      | Polish for "screening" (adjective form); in copy only.                                                             | `screening_*`                                          | a separate concept; a new `przesiew*` identifier                       |
| badania profilaktyczne                                              | Polish for "preventive screenings"; same concept as screening.                                                     | `screening_*`                                          | —                                                                      |
| catalog entry                                                       | One reviewed JSON file in `catalog/entries/`, compiled into `screening_catalog`.                                   | `CatalogEntry`, `catalog/entries/<slug>.json`          | "screening type", "exam type", `exam_rule`                             |
| slug                                                                | The entry's permanent identity; never renamed, never deleted.                                                      | `slug`, `catalog_slug`                                 | id, key                                                                |
| entry status: draft / active / retired                              | draft = hidden; active = shown and recommended; retired = still resolves for old records, no longer recommended.   | `status` (`CATALOG_STATUSES`)                          | `pending_verification`; "deleted" (entries are never deleted)          |
| review stamp                                                        | Who reviewed the entry and when; required for active entries.                                                      | `reviewed_by`, `last_reviewed`, `next_review_due`      | "medical sign-off" (the owner's stamp is not one)                      |
| medical sign-off                                                    | A POZ doctor's review of an entry; a public-launch gate, not done yet.                                             | _missing in code_ (only the `reviewed_by` text)        | the owner's "owner (non-medical review)" stamp                         |
| catalog owner                                                       | The person who reviews entries and sets them active.                                                               | `"owner (non-medical review)"` value                   | admin, doctor                                                          |
| eligibility / branch / condition                                    | An entry applies when any branch matches: sex, age range and every condition.                                      | `BranchSchema`, `ConditionSchema`, `evaluateBranch`    | rule (too vague), JSONLogic                                            |
| factor                                                              | A profile fact a condition tests (smoking, pack-years, …); age and sex are branch fields, not factors.             | `FACTORS`, `FactorId`                                  | risk score                                                             |
| repeat interval — PL **odstęp**, "Jak często"                       | How often a screening repeats: fixed months, or no known interval / shared decision / per program.                 | `interval_kind`, `interval_months`, `resolveInterval`  | frequency, period                                                      |
| evidence level                                                      | 3 = organised NFZ program or USPSTF A/B; 2 = society recommendation or Moje Zdrowie; 1 = shared decision or pilot. | `evidence_level`                                       | grade, priority                                                        |
| burden weight                                                       | Disease burden in Poland, 0–5; only breaks ties when sorting.                                                      | `burden_weight`                                        | score, priority                                                        |
| NFZ-funded / referral — PL **Bezpłatne w NFZ / Wymaga skierowania** | Whether the public payer covers it and whether a referral is needed.                                               | `nfz_funded`, `referral_required`                      | free, prescription                                                     |
| NFZ program                                                         | A screening run by the public payer with its own rules.                                                            | `interval_kind = 'per_program'`, `*-nfz-program` slugs | —                                                                      |
| POZ doctor — PL **lekarz POZ**                                      | The user's primary-care doctor; where the app sends personal decisions.                                            | copy only                                              | GP in Polish copy                                                      |

## Recommendation

| term                                                                                        | means                                                                                                                      | name in code                                         | don't call it                                                                           |
| ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------- |
| recommendation — PL **zalecenia** (lista zaleceń)                                           | A catalog entry that applies to this user's profile now.                                                                   | `Recommendation`, `recommend()`, `classifyEntries()` | "due" (due means due again, see below); "guidance" (that is the entry's medical source) |
| importance tier — PL **Ważne – umów się teraz / Warto zaplanować / Porozmawiaj z lekarzem** | Label 1/2/3 from the evidence level (3→1, 2→2, 1→3); EN "Important — schedule now / Worth planning / Talk to your doctor". | `Tier`, `tierOf()`                                   | priority, rank, score; badge forms "Ważne", "Do rozmowy z lekarzem" are the same tiers  |
| may apply — PL **Może Cię dotyczyć – zapytaj lekarza POZ**                                  | An entry that would apply if a factor the profile does not collect were true.                                              | `MaybeRecommendation`, branch result `unknown`       | eligible, recommended                                                                   |
| age                                                                                         | Current calendar year minus birth year (programs count by birth year); never stored.                                       | `currentYear - profile.birth_year`                   | exact age, age from birthday                                                            |
| Warsaw day                                                                                  | The product's calendar: today, months and years are Warsaw dates.                                                          | `warsawToday()`, `warsawMonth()`, `'Europe/Warsaw'`  | `new Date().getFullYear()`, UTC date                                                    |
| disclaimer                                                                                  | The list is informational only: not a diagnosis, medical advice or a medical device.                                       | `dashboard.recommendations.disclaimer`               | —                                                                                       |
| dashboard — PL **Panel**                                                                    | The signed-in page with tiers, plans and done exams.                                                                       | `/dashboard`, `partitionDashboard()`                 | home                                                                                    |

## Screening follow-through (the user's exams)

| term                                                                    | means                                                                                                                     | name in code                                                                                                | don't call it                                                         |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| exam — PL **badanie**                                                   | One user's handling of one screening: planned, done or due again.                                                         | _missing in code_ — identity `(user_id, catalog_slug)` across `screening_plans` and `screening_completions` | screening (that is the catalog item), record, test                    |
| plan — PL **Twoje plany / Zaplanuj badanie / Dodaj do planów**          | The user intends to do this exam, with or without an appointment date.                                                    | `screening_plans`, `ScreeningPlan`, intent `plan`                                                           | selection, booking, IPZ                                               |
| unplan — PL **Usuń z planów**                                           | Remove the plan.                                                                                                          | intent `unplan`                                                                                             | undo, cancel                                                          |
| appointment date — PL **termin wizyty**, **termin**                     | The date of a visit the user booked outside the app; today to +2 years.                                                   | `appointment_date`                                                                                          | booking, visit date, schedule                                         |
| undated plan — PL **Termin jeszcze nieustalony**                        | A plan with no appointment date yet.                                                                                      | `appointment_date = null`                                                                                   | selected exam                                                         |
| done — PL **Wykonane / Oznacz jako wykonane**                           | The user marks the exam as already done, with an optional month.                                                          | `screening_completions`, `ScreeningCompletion`, intent `done`                                               | completed, handled, "done record" in new names                        |
| undo done — PL **Cofnij oznaczenie**                                    | Delete the done record.                                                                                                   | intent `undone`                                                                                             | unplan                                                                |
| last done — PL **Ostatnio wykonane**                                    | Month (or exact day after confirm) the exam was last done.                                                                | `last_done_month`, `last_done_on`                                                                           | completion date                                                       |
| confirm (an exam) — PL **Czy badanie odbyło się …? / Tak, potwierdzam** | After the appointment date has passed, the user confirms the exam took place on that day; the plan becomes a done record. | `confirm_screening_plan()`, intent `confirm`, `awaitingConfirmation`                                        | mark done (that has no date check); e-mail confirmation (auth)        |
| due again — PL **Następne badanie**                                     | A done exam whose repeat interval has run out; it returns to its tier. EN "Due again".                                    | `nextDueMonth()`, `due_month` (ledger only)                                                                 | "next exam"; "due" alone; recurrence (nothing is scheduled or stored) |
| anchor month                                                            | The month a done exam's interval counts from: last-done month, else the month it was saved.                               | `anchorMonth()`, `screening_anchor_month()`                                                                 | due date                                                              |
| no known interval                                                       | A done exam with no computable next date; the gap is shown to the user.                                                   | `dashboard.screenings.done.noInterval`                                                                      | never due                                                             |
| open screenings — PL **czeka na Twoją decyzję**                         | Screenings still in a tier, with no plan or current done record.                                                          | `openCount`                                                                                                 | due list                                                              |

## Reminders

| term                                                       | means                                                                                                                  | name in code                                                            | don't call it                                                                   |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| reminder emails — PL **Przypomnienia e-mail**              | All the opt-in emails: appointment, due again and the two nudges.                                                      | `runReminderChain()`                                                    | "appointment reminders" for the whole set                                       |
| reminder opt-in — PL **Włącz przypomnienia**               | One switch, off by default, for every reminder email; deleted on withdrawal.                                           | `profiles.reminders_enabled`                                            | appointment opt-in                                                              |
| appointment reminder — PL **przypomnienie o wizycie**      | Email 1–3 Warsaw days before an appointment date.                                                                      | `appointment_reminders`, `runAppointmentReminders()`                    | due reminder (`claim_due_appointment_reminders` uses "due" for "ready to send") |
| due-again reminder — PL **czas na badanie profilaktyczne** | Email when a done exam is due again; once per anchor month.                                                            | `due_screening_reminders`, `runDueScreeningReminders()`                 | recurrence reminder                                                             |
| first-time eligibility reminder                            | Email when a user becomes eligible for a screening for the first time; undecided product question.                     | _missing in code_                                                       | due-again reminder                                                              |
| nudge — PL **przypomnienie o planowanych badaniach**       | Email for a plan with no date after 14 days (`schedule`) or a passed appointment unconfirmed after 7 days (`confirm`). | `follow_up_nudges`, `runFollowUpNudges()`, kinds `schedule` / `confirm` | follow-up reminder; "schedule" as in cron                                       |
| ledger                                                     | The table recording one email per cycle: unsent → sent (claim → send → mark).                                          | `appointment_reminders`, `due_screening_reminders`, `follow_up_nudges`  | queue, log                                                                      |
| daily email budget                                         | 92 emails a day shared by the three jobs, in order: appointment, due again, nudge.                                     | `REMINDER_EMAIL_DAILY_BUDGET`                                           | rate limit                                                                      |

## Consent and profile

| term                                                                 | means                                                                                         | name in code                                          | don't call it                                   |
| -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ----------------------------------------------- |
| health data — PL **dane o zdrowiu**                                  | Profile answers and exam dates; GDPR Art. 9; never in URLs, logs, emails or AI.               | no type (table comments)                              | personal data (broader)                         |
| consent — PL **Zgoda na przechowywanie danych o zdrowiu**            | Explicit, separate consent to store health data; one active per user.                         | `health_data_consents`, `HEALTH_DATA_CONSENT_VERSION` | terms acceptance, e-mail confirmation           |
| active consent                                                       | A consent row not yet withdrawn.                                                              | `withdrawn_at is null`, `hasActiveConsent()`          | active entry (catalog status)                   |
| withdrawal — PL **Wycofanie zgody**                                  | Deletes profile, plans, done records and ledgers in one step; keeps the consent row as proof. | `withdraw_health_data_consent()`                      | account deletion, sign-out                      |
| health profile — PL **Twój profil zdrowotny**                        | Birth year, sex at birth and smoking history used by the rules.                               | `profiles`, `Profile`, `RuleProfile`                  | the `/profile` settings page (PL "Twój profil") |
| onboarding state                                                     | needs consent → needs profile → complete; derived, not stored.                                | `OnboardingState`, `getOnboardingState()`             | sign-up                                         |
| sex at birth — PL **Płeć przy urodzeniu**                            | Female or male at birth; used only to match screenings.                                       | `sex` (`female` / `male`)                             | gender                                          |
| smoking status / pack-years — PL **Palenie papierosów / Paczkolata** | never / current / former, with packs per day × years.                                         | `smoking_status`, `pack_years`                        | —                                               |

## Words with several meanings

| word      | in this product it means                             | other meanings — use another word                                                                                                                                |
| --------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| due       | due again (a done exam's interval ran out)           | recommended now → "recommendation"; ready to send → "claimable"; appointment not yet passed → "not yet passed" (`'not_due'`); catalog review date → "review due" |
| badanie   | screening (catalog) or exam (user's) — say which     | —                                                                                                                                                                |
| confirm   | confirm an exam took place                           | e-mail confirmation (auth); withdrawal acknowledgement                                                                                                           |
| schedule  | the `schedule` nudge kind (plan has no date)         | cron → "cron"; booking a visit → "book" (PL "umów się")                                                                                                          |
| zalecenia | the user's recommendation list                       | the medical guidance an entry cites → "guidance"                                                                                                                 |
| active    | active entry (catalog) or active consent — say which | —                                                                                                                                                                |
| plan      | the user's planned exam                              | IPZ (individual health plan); a 10x `plan.md`                                                                                                                    |
| profile   | the health profile                                   | the `/profile` page                                                                                                                                              |
